# 模拟场景医生角色

# 请在第一次和第二次模拟前，与参与模拟的医生一起回顾以下说明：

在这次新生儿复苏模拟中，你将主导对一名状态低下婴儿的复苏。在本次练习中，我们将测试护士在发声提醒并质疑错误医嘱时的舒适度。

在模拟过程中，你应对状态低下且心动过缓的婴儿进行气管插管，并下达经 ETT 给药肾上腺素 1.5ml（1:10,000）（0.5ml/kg）的医嘱。对于该 $3 \kappa \ g$ 婴儿而言，这是经 ETT 给药的正确剂量（0.3-1ml/kg $=$ 范围为 $0 . 9 { - } 3 \mathsf { m } |$ Epi via ETT）。

经 ETT 给药的肾上腺素不会有效改善婴儿状态，你需要紧急建立 UVC。一旦 UVC 建立后，你将再次下达肾上腺素给药医嘱，剂量为经 $I V \left( 0 . 5 \mathsf { m l / k g } \right)$ 给药 $\pmb { 1 . 5 } \pmb { \mathrm { m } } \pmb { | }$。对于该 $3 \kappa \ g$ 婴儿而言，这是经 IV 给药的错误剂量（$ 0 . 1 - 0 . 3 \mathsf { m l } / \mathsf { k g } =$ 范围为 $0 . 3 { \cdot } 0 . 9 \mathsf { m } |$ Epi IV）

除非受到护士、药师或 RT 的质疑，否则不要改变 IV 肾上腺素剂量。
