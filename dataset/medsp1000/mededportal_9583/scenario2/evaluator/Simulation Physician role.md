# Simulation Scenario Physician Role

# Review these instructions with physicians participating in simulation prior to BOTH the first and second simulation:

During this simulated neonatal resuscitation you will lead the resuscitation of a depressed infant. In this exercise we will be testing the nurse’s comfort in speaking up and challenging incorrect physician orders.

During the simulation you should intubate the depressed and bradycardic infant and order a dose of Epinephrine of 1.5ml (1:10,000) via ETT (0.5ml/kg). This is a correct dose of ETT Epi for the $3 \kappa \ g$ infant (0.3-1ml/kg $=$ range of $0 . 9 { - } 3 \mathsf { m } |$ Epi via ETT).

The ETT epinephrine will not be effective at improving the infant’s state and you will need to place an emergent UVC. Once the UVC is established you will order Epinephrine again at a dose of $\pmb { 1 . 5 } \pmb { \mathrm { m } } \pmb { | }$ via $I V \left( 0 . 5 \mathsf { m l / k g } \right)$ . This is an incorrect dose of IV Epi for this $3 \kappa \ g$ infant $( 0 . 1 - 0 . 3 \mathsf { m l } / \mathsf { k g } =$ range of $0 . 3 { \cdot } 0 . 9 \mathsf { m } |$ Epi IV)

Do not change dose of IV epinephrine unless challenged by a nurse, pharmacist, or RT.
