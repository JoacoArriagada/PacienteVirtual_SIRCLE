**CSAP Adolescent Medicine Scenario**

<u>**Background**</u>

You are seeing a teenager for their yearly well physical. You have already discussed the families concerns with the parent in the room. The parent has now stepped out of the room to allow you some private time with the teen.

<u>**Duties**</u>

Please perform a psychosocial history using the SCAG as a guide.

There is no Physical exam for this exercise.
