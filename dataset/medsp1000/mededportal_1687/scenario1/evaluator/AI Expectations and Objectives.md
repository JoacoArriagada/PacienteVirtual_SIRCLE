# Expectations for Acting Interns (GW site):

1. See & evaluate patients from ER $\mathbf { \delta } _ { - > }$ write admission orders $_ { - > }$ formulate plans of care $\mathbf { \delta } _ { - > }$ anticipate discharge & follow-up planning

2. Actively participate in at least one patient/family meeting (eg., family meetings that inform a new diagnosis, discussing long-term treatment options,palliative care/end-of-life discussions).

3. Become aware with the systems of care, the teamwork and communication needed between the medical team, the case managers,and the patient/family members.

4. Be exposed to, or respond to a code or rapid response activation. Try to avoid being tasked with chest compressions - you need to see how experienced residents/fellows run these crisis situations.

5. Have the opportunity to perform (or assist with) basic inpatient procedures: thoracentesis, paracentesis, lumbar puncture, central catheter placement.

6. Attend and present a patient at morning report.
