| Mental Status Exam Checklist: OBSERVER VERSION | |
| ***Instructions:*** At the end of an interview, students are expected to present and document the mental status examination. Use this checklist to help construct feedback. | |
|  | **Use this space to describe your own observations and to take notes to be used for feedback** |
| **Appearance** | |
| *Describes stated age* |  |
| *Describes attire* |  |
| *Describes grooming and hygiene* |  |
| *Describes presence or absence of physical abnormalities* |  |
| **Behavior** | |
| *Describes eye contact* |  |
| *Describes attitude toward examiner* |  |
| *Describes level of consciousness* |  |
| **Motor Activity** | |
| *Describes the presence or absence of unusual mannerisms and/or movements* |  |
| *Describes the presence or absence of psychomotor agitation or retardation* |  |
| **Speech** | |
| *Describes fluency* |  |
| *Describes volume* |  |
| *Describes quantity* |  |
| *Describes rate* |  |
| *Describes tone* |  |
| **Mood** | |
| *Describes patient stated mood* |  |
| **Affect** | |
| *Describes affect type* |  |
| *Describes range* |  |
| *Describes reactivity of affect to external factors* |  |
| *Describes stability vs lability* |  |
| *Describes appropriateness* |  |
| *Describes congruence to mood* |  |
| **Thought Processing** | |
| *Describes goal directedness* |  |
| *Describes tightness of associations between words/ideas* |  |
| **Thought Content** | |
| *Describes the presence or absence of overvalued ideas* |  |
| *Describes the presence or absence of delusions* |  |
| *Describes the presence or absence of suicidal ideation, intent, plan* |  |
| *Describes the presence or absence of homicidal ideation, intent, plan* |  |

| *Describes the presence or absence of hallucinations/illusions* |  |

| *Describes orientation in three spheres (person, place, time)* |  |
