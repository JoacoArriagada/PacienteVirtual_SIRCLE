# VII. Instructor Notes

A. Tips to keep scenario flowing 1. If need for further evaluation not recognized, nurse will make a suggestion for further evaluation or Cardiology consultation. 2. Nurse will prompt learners to obtain baseline ECG if not requested. 3. Nurse will prompt learners to place defibrillation pads if not requested. 4. Each time the patient complains of dizziness, the learners should request a new ECG.   
B. Scenario programming 1. Optimal management path  $\mathrm { O } _ { 2 } / \mathrm { I V } / \mathrm { I }$ monitor  History and physical examination Requisite studies o Labs: CBC, BMP, cardiac markers, coagulation profile o Images: ECG, CXR Place defibrillation pads Initiate chronotropic infusions Initiate transcutaneous pacing Call expert consultation (Anesthesia for sedation) Call expert consultation (Cardiology for transvenous pacing)

2. Potential complications/errors path(s)

 Failure to recognize unstable bradycardia   
 Administration of atropine in setting of complete heart block   
 Inappropriate medication dosing   
Failure to initiate transcutaneous pacing in patient unresponsive to chronotropic infusions   
. Failure to call Anesthesia for appropriate airway management
