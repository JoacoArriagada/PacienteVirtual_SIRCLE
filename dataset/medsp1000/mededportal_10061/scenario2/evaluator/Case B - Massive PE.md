# III. Learning and Assessment Objectives

Participants are expected to execute the optimal management path as defined below and through the critical actions checklist as well as discuss the pathophysiologic reasoning behind a certain course of treatment. Debriefing sessions may be used to allow each participant to reflect upon the team dynamics and to identify future technical and behavioral goals.

Critical Actions Checklist:

# VII. Instructor Notes

A. Tips to keep scenario flowing 1. If need for further evaluation not recognized, nurse will make a suggestion for further evaluation, calling the supervising resident, calling a consultant, or administering a medication. 2. Nurse will prompt learners to obtain baseline ECG, CXR, and bedside transthoracic echocardiogram if not requested.   
B. Scenario programming 1. Optimal management path  $\mathrm { O } _ { 2 } / \mathrm { I V } /$ monitor  History and physical examination Requisite studies o Labs: BMP, CBC with differential, cardiac markers, coagulation profile o Images: ECG, CXR, TTE, RLE doppler IV fluid resuscitation  Anticoagulation . Order STAT bedside TTE and consult Cardiology Administer lytic therapy

2. Potential complications/errors path(s):

. Failure to notice right heart strain pattern and $S _ { \mathrm { I } } ,$ ， $\mathrm { Q } _ { \mathrm { I I I } }$ , $\mathrm { T _ { I I I } }$ pattern on ECG   
Administration of beta blockade or other nodal agent to treat sinus tachycardia   
Administration of too much IV fluids leading to right ventricular overload and worsening hypotension   
Failure to consider anticoagulation and lytic therapy
