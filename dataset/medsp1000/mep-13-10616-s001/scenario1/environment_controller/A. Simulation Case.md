| **Appendix A: MedEdPORTAL Simulation Case**  **SIMULATION CASE TITLE: “A complicated opioid overdose: a simulation for emergency medicine residents”** | |
| **PATIENT NAME: John Doe**  **PATIENT AGE: 31**  **CHIEF COMPLAINT: Unresponsive** | |
|  | |
| **Learner Preparation** | The patient is a 31 year-old male who presents to the ER by EMS after he was found unresponsive in a nearby park by his friends. He is only producing agonal respirations. |

|  |  |  |  |
| --- | --- | --- | --- |
| Initial Presentation | | | |
| **Initial vital signs** | T 37.4oC, BP 110/75, HR 110, RR: agonal, O2% Sat: 65% | | |
| **Overall Appearance** | Patient is unresponsive with agonal respirations | | |
| **Standardized patient (SP) and roles in the room at case start** | At the start of the case, the SP playing the role of the patient can play the role of EMS dropping the patient off. | | |
| **HPI** | EMS informs the learners that the patient was found unresponsive. His friends informed the EMS personnel that before going unresponsive, the patient had injected heroin. EMS administered 0.4 mg of naloxone on the ambulance during the 5-minute transport time before arrival without any effect. | | |
| **Past Medical/Surgical History** | **Medications** | **Allergies** | **Family History** |
| Asthma | Albuterol inhaler | None | None |
| **Physical Examination** | | | |
| **General** | Patient is initially unresponsive, but appears dyspneic after revival with naloxone | | |
| **HEENT** | Pupils are initially 2 mm and minimally reactively. They dilate to 4 mm after naloxone administration and are reactive. | | |
| **Neck** | No pertinent findings | | |
| **Lungs** | Initially, patient’s respiratory rate is profoundly low. Lung sounds are equal bilaterally without wheezes, rales, rhonchi. After administration of naloxone, patient’s respiratory rate increases and he becomes dyspneic. Reevaluation demonstrates bilaterally rales on auscultation. | | |
| **Cardiovascular** | Regular tachycardic rhythm | | |
| **Abdomen** | Soft and non-tender on exam. | | |
| **Neurological** | GCS 3 on arrival. GCS 15 after appropriate naloxone administration. Eyes open, confused and mumbling, not following commands. GCS 13 | | |
| **Skin** | No pertinent findings | | |
| **GU** | No pertinent findings | | |
| **Psychiatric** | No Pertinent findings | | |

| Instructor Notes - Changes and CASE Branch Points | | |
| **Intervention / Time point** | **Change in Case** | **Additional Information** |
| *Naloxone given* | *Patient rapidly responds to naloxone. GCS increases to 13.*  *New vitals: BP 138/72, HR 124, RR 45, O2% Sat 52% NRB, Temp 36.5oC* | *GCS – 2 points for inability to follow commands (localizes painful stimuli) and confusion* |
| *Learners reassess the patient* | *Patient responds to learner questions and provides history described above* |  |
| *5 minutes after naloxone is given* | *Patient becomes progressively dyspneic, respiratory rate increases, O2% sat drops to 60%* | *Patient may state “doc it’s getting really hard to breath”* |
| *5 minutes after patient develops dyspnea* | *If no attempt has been made to improve the patient’s oxygenation, the patient’s vitals begin to get progressively worse* | *A “nurse” (the SP for the patient’s voice) should enter the room briefly and ask the learners if they want to do anything for the patient’s vitals* |
| *Learners reassess patient* | *Rales are present on physical exam* | *If learners ask for CXR at any point after this, a CXR is provided that demonstrates bilateral pulmonary edema* |
| *Learners may attempt duo-neb or albuterol based on the history above* | *No change* | *Patient may state “doc I’m really struggling here. What’s happening?”* |
| *Learner may attempt NIPPV* | *No change* | *Patient struggles against the mask and constantly removes it* |
| *Either after patient has attempted one of the above interventions or after 5 minutes* | *Patient begins to deteriorate (RR decreases to 8, O2% Sat 60%, GCS 7)* |  |
| *RSI Intubation or awake intubation* | *If successful: No change to O2% sat*  *If unsuccessful: Patient’s vitals drop precipitously* |  |
| *Learner should set ventilator to lung protective settings* | *No change* |  |
| *Learner should recognize need for ECMO* | *Case ends* | *If ECMO is performed by the emergency physicians at the learner’s institution, they can set it up based on local protocol. If it is not, they must recognize*  *the need and make appropriate consults* |
