| **SIMULATION CASE TITLE:** Acute inflammatory demyelinating polyneuropathy (AIDP) with acute respiratory failure | |
| **PATIENT:** Green  **PATIENT AGE:** 35 year old  **CHIEF COMPLAINT:** Generalized Weakness | |
| **Brief narrative description of case** | A 35 year old patient is directly transferred to a regular medical/surgical floor at University Hospital from an outside hospital emergency department with 1 week of progressive weakness due to AIDP. The patient develops acute respiratory weakness, which the learner must recognize and manage, initially with non-invasive ventilation and then eventually with intubation and transfer to ICU. |

This role can also be played by the RN confederate.  **ICU fellow:** Facilitator- Questions and accept transfer at the end.  **Simulation Jockey:** Facilitator or sim center staff- Adjust vital signs and give labs/images as the case progresses. | | |

| Obtains full set of VS | If yes -> | BP: 120/80 HR: 110 RR: 24 SpO2: 99 Temp: 97 (displayed on monitor) |
|  | If no -> | RN can ask "Would you like me to get a set of vital signs?" |
|  | If still no -> | RN says "I'm going to get some vital signs. Do you want the patient on tele?" |
| Recognize/verbalize abnormal vitals | If yes -> | Continue case |
|  | If no -> | RN prompts: "I just hooked up the tele and checked the vitals." |
|  | If still no -> | Patient says: "I'm feeling a little short of breath and I feel like my heart is racing." |
| Perform high-yield neuromuscular exam (if not previously done) - neck flexion - breath counting | If yes -> | Continue case |
|  | If no -> | RN prompts: "The patient is weak and short of breath. Is there anything else to check on exam?" |
|  | If still no -> | RN prompts: "The patient could barely lift the head off the pillow." |
| Call respiratory therapist (RT) and request NIF/FVC and ABG | If yes -> | RN tells learners the PFTs: NIF -20, FVC 1L. ABG displayed on screen: pH 7.32, PCO2 50, PO2 80, bicarb 32. |
|  | If no -> | - Vitals worsen HR 120s RR 30s  - Patient develops more labored breathing and has difficulty completing sentences.  - RN says: "It seems like the breathing is bad. Anything you want to check?" |
|  | If still no -> | RN says: "Should we call RT?" |
| Order diagnostic tests | If yes -> | Show labs and imaging on screen  - chest x-ray and CT head normal  - complete blood count, basic metabolic panel, CK normal  - ABG as above |
|  | If no -> | RN says: "Do you want to order any labs or tests?" |
|  | If still no -> | RN says: "Should we get chest x-ray, blood gas, and other labs?" |
| Start non-invasive ventilation (NIV)/BIPAP | If yes -> | RN places BIPAP. Starts at 100% FiO2. |
|  | If no -> | Patient says: "I feel very short of breath. Can you give me anything to help?" |
|  | If still no -> | RN says: "Should we try BIPAP?" |
| Recognize/verbalize patient's decline in mental status and respiratory status despite NIV | If yes -> | Continue case |
|  | If no -> | Patient starts snoring and grunting. Does not respond or interact. Vitals worsen: HR 140s SpO2 drops to 80s. |
|  | If still no -> | RN says: "I'm really worried about the patient. Does the patient need a higher level of care?" |
| Call anesthesia for STAT intubation and transfer to ICU | If yes -> | ICU fellow calls for sign-out |
|  | If no -> | - SpO2 drops to 70s.  - RN says: "I'm really concerned that the patient's O2 sats are dropping and the patient can't protect the airway." |
|  | If still no -> | RN says: "Should we intubate the patient?" |
| Sign out case to ICU fellow | If yes -> | Facilitator acting as ICU fellow will call and receive sign-out from learner. END OF CASE. |
