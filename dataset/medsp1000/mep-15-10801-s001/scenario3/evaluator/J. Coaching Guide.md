# Debriefing

• Allow the conversation to be organic; people may raise such issues themselves, which is great because then there is a greater level of ownership. If the actors or audience members never raise the concepts, follow whatever discussion there has been by pointing out how the action/dynamic might be reflective of these concepts. Avoided the use of specific foundational language (e.g., oppression, privilege) as it may set up walls and cut off communication, rather than facilitating it and/or it may trigger defenses.

Useful questions

o What happened here? (This question is likely to elicit different responses. Probe for responses relating both to the actual action and perceived dynamics underlying the action.)   
o Did the experience evoke specific emotions, feelings or thoughts?   
$\bigcirc$ Would you want to change any part of the scene? What part(s)? Why?   
$\bigcirc$ Did the scenario portray any implicit or explicit bias?   
$\bigcirc$ Would anyone like to act out that change?
