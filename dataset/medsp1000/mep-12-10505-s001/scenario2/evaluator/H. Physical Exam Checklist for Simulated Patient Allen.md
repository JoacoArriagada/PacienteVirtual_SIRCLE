**Learner Physical Examination Checklist & Guide (for Part A)**

|  |  |  |  |
| --- | --- | --- | --- |
| **1.** | **Item:** Wash hands. | Yes  No | |
| **2.** | **Item:** Stand to the right of the patient. Ask the patient to expose the entire abdomen, draping the pelvic area and lower extremities. | Yes  No | |
| **3.** | **Item:** Verbalize inspection of abdomen for color, contour, symmetry, and movement. | Yes  No | |
| **4.** | **Item:** Auscultate abdomen (prior to palpation or percussion) in all four quadrants (right upper, right lower, left upper, left lower). | Yes  No | |
| **5.** | **Item:** Palpate abdomen LIGHTLY in all four quadrants (right upper, right lower, left upper, left lower). | Yes  No | |
| **6.** | **Item:** Palpate abdomen DEEPLY in all quadrants (right upper, right lower, left upper, left lower). | | Yes  No |
| **7.** | **Item:** Check for rebound tenderness: deep palpation with quick release of hand in four quadrants. Ask if patient feels pain with palpation or release of hand. | Yes  No | |
| **8.** | **Item:** Percuss abdomen in all four quadrants (right upper, right lower, left upper, left lower). | | Yes  No |
| **9.** | **Item:** Palpate liver edge: place left hand on back between right rib cage and hip; place right hand in right upper quadrant pressing inward and upward. Ask the patient to take a deep breath as the edge is palpated. | | Yes  No |
| **10.** | **Item:** Percuss liver span: begin percussing in the right lower quadrant and proceed proximally until the transition from tympanic to dull identified. Then, begin in the right mid-clavicular line over the lung and proceed over the anterior chest until the transition between resonance and dull is identified. | | Yes  No |
| **11.** | **Item:** Palpate spleen: place left hand on back behind left rib cage and lift; place right hand in left upper quadrant pressing inward and upward while asking the patient to take a deep breath. | | Yes  No |
| **12.** | **Item:** Palpate aorta in the upper abdomen slightly to the left of the midline. | | Yes  No |
| **13.** | **Item:** Ask the patient to sit up and percuss costovertebral angles bilaterally using fist percussion over your hand with palm placed on the costovertebral angle to assess for kidney tenderness. Ask if patient feels pain. | | Yes  No |

**Note for administration**: Students are provided with full list of potential history questions in order to prepare for the event. However, only those items highlighted in yellow were rated by simulated patients during the actual event.
