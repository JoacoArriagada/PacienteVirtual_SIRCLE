## 1.5. Meds: metoprolol, ASA, statin, heparin @500 u/hr, Percocet

# 2. **Setting the Scene**

## 2.1. The nurse calls:  “His eyes are rolling back in head” intermittently

## 2.2. Vitals:  HR 60 irregular on telemetry, BP 88/42 , RR 18, SpO2 98%

## 2.3. Labs: Hgb 8.8, INR 1.6, PTT 32, ABG: 7.42/36/98/28

## 2.4. Telemetry—intermittent 3rd degree heart block.  Several pauses seen.

# 3. Evaluation and Resuscitation sequences

1. **Initial Evaluation and Response**

    6. Exam
    7. Pt awakens and rhythm changes if paced correctly.
    8. If not: code blue, asystole, death
