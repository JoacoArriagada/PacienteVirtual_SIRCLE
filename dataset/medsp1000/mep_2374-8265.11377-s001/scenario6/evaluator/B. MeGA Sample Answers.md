# Como se trata

El albuterol es un medicamento de rescate que funciona rapido para mejorar el ataque. Se respira con un aparato como el inhalador de Clara. La doctora le ensena a Clara a usar el inhalador de forma que haga el mayor efecto:

1. Agite el frasco y conecte el espaciador   
2. Sague el aire de los pulmones   
3. Coloqueel inhaladorenla boca, apretando los labios   
4. Presione el frasco   
5. Respire profundo yaguante por 10 segundos

![](images/c37f4481497c1b37b783aa499caa663ab4803a02f47925f85459e53074e08396.jpg)
