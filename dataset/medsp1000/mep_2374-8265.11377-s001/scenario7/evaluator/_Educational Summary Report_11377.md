# Educational Objectives

By the end of this activity, learners will be able to:

1. Verbally explain common diagnoses in Spanish when a patient presents for an acute concern.   
2. Verbally explain common treatment plans in Spanish when a patient presents for an acute concern.   
3. Verbally explain common instructions for follow-up care in Spanish when a patient presents for an acute concern.   
4. Reduce the use of unexplained Spanish medical jargon to improve patient-centered communication with Spanishspeaking patients.
