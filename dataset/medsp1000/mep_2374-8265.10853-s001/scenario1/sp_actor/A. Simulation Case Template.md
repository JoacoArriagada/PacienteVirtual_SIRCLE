| PATIENT NAME: Lucia Martinez  PATIENT AGE: 31 years old, female  CHIEF COMPLAINT: Seizures | |

|  |  |  |  |
| --- | --- | --- | --- |
| Actors and roles in the room at case start | *Actor: Family member. Enter while patient is seizing after physical exam. Speak only in Spanish, repeatedly ask what is wrong, and ask for the doctor to please help. Continue to be intrusive until the learner either speaks fluently in Spanish to you, or until the interpreter enters the room. If neither of the above occur, do not use broken English; instead continue speaking only in Spanish saying “Disculpe, yo no hablo ingles.” (English Translation: “Excuse me, I do not speak English”). If a non-fluent learner attempts to speak to you in Spanish, respond that you do not understand, continue speaking to them at a normal pace. If no interpreter is requested in 10 minutes, you can ask the nurse for an interpreter.* | | |
| HPI | *Patient’s family member will not volunteer information unless properly asked in Spanish, at which point they will provide accurate answers to the learner’s questions. They should not volunteer the patient’s obstetric history unless specifically asked (including if asked about recent hospitalizations).* | | |
