| **Appendix E: Ebola Preparedness Simulation Case**  **SIMULATION CASE TITLE: Supportive care for EVD patient with sepsis**  **AUTHORS: DA O’Keeffe, C Pozner, R Akineni.** | |
| **PATIENT NAME: John Grant**  **PATIENT AGE: 42**  **CHIEF COMPLAINT: Sepsis secondary to acute infection with Ebola Virus Disease** | |

|  |  |
| --- | --- |
| **Learner Preparation** | Learners are given history and presenting complaint as outlined below. They are instructed to don their PPE prior to entering room and then to enter room to assess and care for patient as per their usual clinical practice. |

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| Initial Presentation | | | | | |
| **Overall Appearance** | Mannequin is dressed in hospital garb and is laying at 45° in a bed with a blanket over the legs and abdomen. The mannequin is not initially attached to the cardiac monitor or pulse oximeter. The mannequin will have a urinary catheter with a drainage bag hanging off of the side of the bed that has 700 ml of fluid simulating urine. The mannequin will be placed on typical hospital linens with an absorbable under pad that has material simulating stool on the pad. The rest of the room should appear as a patient isolation room. | | | | |
| **Actors and roles in the room at case start** | No confederates / actors in the room. Two participants will enter the room and proceed to perform basic care procedures on the patient. | | | | |
| **HPI** | Patient presented to ED with flu-like symptoms and a history of recent travel to an Ebola affected area in Africa. He was assessed initially and found to warrant admission for treatment of sepsis. The patient has been transferred to this isolation unit and participants are the medical team assigned to reassess and care for the patient. | | | | |
