# **Appendix D: Standardized Patient Formative Feedback Rubric**

Primary Case Series Author & Standardized Patient Educator: Kristen Fletcher, MD

***Instructions:*** *The standardized patient uses this rubric to rate how the “intern” completed each task below after role-playing the simulated case. The standardized patient gives the completed rubric to the participating "intern” prior to the large group debrief for the case.*

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| **NURSE Mnemonic** | **Description** | **Excellent** | **Adequate** | **Needs Improvement** | **Not Completed** |
| 1**. N**ame | State the emotion.  Example: *“It sounds like you were really**frightened when you got that news.”* |  |  |  |  |
| 2. **U**nderstand | Empathize with/legitimize the emotion *without* implying you understand what someone is feeling.  Example: *Active listening without interruption, follow-up questions to show understanding.* |  |  |  |  |
| 3. **R**espect | Accept their perspective, validate that their reaction is important, and/or give praise.  Example: *“The medical team has noted how you are at bedside day and night, caring for your loved one."* |  |  |  |  |
| 4**. S**upport | Show support, demonstrate partnership, or provide opportunities for family engagement.  Example: *“It sounds like we have the same primary goal in mind, which is…”* |  |  |  |  |
| 5. **E**xplore | Ask the patient/family member to elaborate on their emotions.  Example: *“Is there anything else that is troubling you about this situation?”* |  |  |  |  |

**Description of Rubric Categories:**

**Excellent**: Student applied the communication tool using suitable verbal and nonverbal cues (e.g. calm tone of voice, open posture and facial expression, appropriate eye contact, etc.) and incorporating the patient’s specific needs and context into the response.

**Adequate**: Student used the communication tool listed but could have tailored it more to the patient’s specific needs or context; used some suitable verbal and nonverbal communication cues but left room for improvement.

**Needs Improvement:** Student attempted to use the communication tool but fell into a communication pitfall (see specific cases for examples) or used aggressive/escalating tone, body language, or eye contact (e.g. closed posture, eye contact avoidance, raised voice, etc.)

**Not completed**: Did not use the communication tool.
