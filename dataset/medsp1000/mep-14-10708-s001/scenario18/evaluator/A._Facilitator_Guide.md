Verbal order for an IV pain medication – preferably labetalol $1 0 { - } 2 0 \ \mathsf { m g } \ \mathsf { N }$ or hydralazine 10-20

Clear, closed-loop communication when relaying orders to nursing staff   
Ask nurse to recheck blood pressure in 1-2 hours and page with result (or give parameters for   
which to page)

# Teaching points:

An isolated BP reading should not be used to make clinical decisions – look at the trend, recheck   
BP   
With severe hypertension (Severe HTN: SBP>179 and/or ${ \mathsf { D B P } } { > } 1 1 9 - 1$ , it is important to assess for   
symptoms that would suggest hypertensive emergency – headache, vision changes, nausea,   
chest pain   
There are several IV agents that can be used for lowering the blood pressure, however, the most   
common in our hospital are labetalol or hydralazine. Goal is $< 1 6 0 / < 1 0 0$ , but no more than 25-   
$30 \%$ decrease in first day   
If there is concern for hypertensive emergency, patient will need to be placed on an infusion   
and transferred to a unit that can accommodate titration of drips (nitroprusside, labetalol)   
Think about other potential contributing factors such as pain, $\mathsf { n } / \mathsf { v } _ { i }$ , alcohol withdrawal, opioid   
withdrawal
