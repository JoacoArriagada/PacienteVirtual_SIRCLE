# 儿科情景4 – 感染性休克

# 目标：

1. 识别感染性休克的临床表现。   
2. 处理休克所致的相对低血容量。   
3. 识别哪些患者属于脓毒症高风险人群。

情景：一名 5 岁男童，发热 2 天（$\left( \mathrm { T } _ { \mathrm { m a x } } 3 9 . 8 \right)$）并伴乏力。患儿有急性淋巴细胞白血病，4 天前接受了诱导化疗。父母在午夜将其紧急送来，因为无法将其唤醒。

既往史提示已化疗 2 个月。患儿有右侧锁骨下中心静脉导管，近期曾因导管感染更换。

用药：对乙酰氨基酚和布洛芬，Bactrim（TMP-SMX，每周一/三/五），Zantac（雷尼替丁）无过敏史。

体格检查：说明患儿皮肤花斑、面色灰暗，并有散在瘀点。

T 39.2 P 146 RR 44 BP 68/38 $S _ { \mathrm { a } } O _ { 2 }$ : 80’s

体重：估计 $2 5 \mathrm { k g }$（仅在被问及时提供）

一般情况：对疼痛刺激反应极少——呻吟，缓慢回撤

气道：通畅

呼吸：呼吸音清。

循环：心动过速、脉搏细弱而快、四肢发凉。可见细小瘀点样皮疹并有少量紫癜区。其余查体正常。

无额外病史
