**DELIVERY ROOM COMMUNICATION CHECKLIST**

This checklist is a communication guide for Obstetric (OB) and Pediatric (Peds) teams who provide maternal or newborn care during deliveries. Please review the communication items below.

|  |  |
| --- | --- |
| **CHECKLIST ITEMS**  *(Items should either be stated or determined by asking.)* | **Item performed?** |
| **Information exchanged between OB and Peds, when OB calls and asks the Peds to attend a delivery**   * *OB: State each checklist item in this section to the Peds team.* * *Peds: Ask the OB team for information that was either not communicated or needs clarification.* | |
| Brief reason why the pediatric team is needed |  |
| Infant’s gestational age |  |
| Pertinent maternal risk factors (If there are none, it should be stated.) |  |
| **Information exchanged between OB and Peds when Peds team arrives at the delivery**   * *OB: State checklist items in this section to the Peds team.* * *Peds: Ask the OB team for information that was not communicated or needs clarification.* | |
| Peds team’s announcement of their arrival at the delivery |  |
| Brief reason why the pediatric team is needed |  |
| Gestational age |  |
| Pertinent maternal risk factors (If there are none, it should be stated.) |  |
| Maternal medications, including pertinent over-the-counter drugs (If there are none, it should be stated.) |  |
| Time of infant’s birth, or how old the infant is in minutes during hand-off |  |
| Any resuscitation measures done for the infant by the obstetric team (if applicable) |  |
| Peds team’s communication that they either require additional support, or have sufficient resources to continue resuscitation on their own |  |
| APGAR score assignment by OB team prior to arrival of pediatric team (if applicable) |  |
| **Information exchanged on infant status between OB and Peds, after Peds stabilizes the infant**   * *Peds: State checklist items in this section to the OB teams.* * *OB: Ask the Peds team for information that was not communicated or needs clarification.* | |
| Resuscitative efforts on infant |  |
| Infant’s current clinical status |  |
| Where the infant will be admitted |  |
| APGAR scores |  |
| **Information communicated by Peds to the infant’s family, either during or after infant stabilization**   * *Peds: Perform checklist items in this section as specified when communicating with the family.* | |
| Introduce yourself to the mother and family |  |
| Discuss infant’s current clinical status |  |
| State measures done to help the infant transition |  |
| Communicate where the infant will be admitted |  |
| Discuss why NICU care is required (if applicable) |  |
| Offer to answer any questions |  |
| Offer to let the mother see, touch, and/or hold the baby |  |
