| Brief narrative description of case | The patient presents with sudden onset chest heaviness radiating to his jaw, anxiety, diaphoresis and nausea. His symptoms are progressively worsening since onset 1 hour ago and arrives to the ED ill appearing. |

This was associated with chest heaviness radiating to the jaw and mild shortness of breath that have been getting progressively worse since onset. He denies any history of similar symptoms. | | |

| Instructor Notes - Changes and CASE Branch Points | | |
| Intervention / Time point | Change in Case | Additional Information |
| After initial assessment, learners request EKG | Provide the EKG showing lateral STEMI. | If no EKG is requested, RN will prompt learners by asking if they are concerned about his chest pain. |
| Learners call cardiology | Cardiologist says, “I want to take this patient to the cath lab…. how are you sending this patient, air or ground.” |  |
| After plans for transportation made, patient states “I don’t feel so good” and becomes unresponsive | Patient becomes unresponsive. | If learners do not check for a pulse and start chest compressions, simulationist or nurse confederate (if available) will prompt, “should I call a code?” |
| At the 2 minute rhythm check | Rhythm changes to Ventricular Tachycardia. | If learners need prompting, simulationist or nurse confederate (if available) can ask whether any other drugs are indicated for this arrhythmia. |
| Intubation | Intubation becomes necessary only if learners do not recognize pulseless V Tach and do not initiate care consistent with ACLS protocols. |  |
| Post Cardiac Arrest Care | If the patient was intubated, post-cardiac-arrest care includes therapeutic hypothermia. If the patient responded quickly to ACLS and is awake, this is not necessary. |  |
