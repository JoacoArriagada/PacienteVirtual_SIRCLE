**Critical Skills for the Senior Medical Student Entering Surgery**

**Post-Op MI Module**

**Patient Information and History**

* 61 year-old male with PMH significant for hypertension, diabetes, peripheral arterial disease, and tobacco use
* POD 1 s/p right femoral to popliteal artery bypass
* Called by nurse because patient has chest discomfort

**Setting the Scene**

* Pt complains of chest discomfort that came on fairly suddenly
* IV is heparin-locked. Patient is tolerating clears.
* Baseline VS: 98.3, 92 regular rhythm, BP 118/76, RR 32, SPO2 100%
* Initial Labs: Hgb 9.9, ABG 7.42/38/100/21, 99%, trop < 0.04
 
**Evaluation and Response Sequences**

|  |  |  |
| --- | --- | --- |
| **Operator Action** | | **Student Action** |
| 1 | Evaluation and Initial Response | |
| Patient appears diaphoretic, and reports chest pain radiating into left arm and jaw.   * *If student gives sublingual ntg, pain improves* * *If student obtains EKG, shows ST elevations in inferior leads, regular sinus rhythm* * *If student orders troponin, it is normal upon initial draw*   Patient’s pain continues if student fails to provide oxygen, give analgesic, ntg   * *Patient continues to complain of chest pain*   If EKG is not done, or MI is otherwise not diagnosed, pt develops arrhythmia, SOB, and progresses to cardiorespiratory collapse   * *Patient eventually expires*   If student starts heparin or sends patient to the cath lab WITHOUT discussing with operating attending surgeon, patient exsanguinates from operative field   * *incision starts oozing, pt develops tachycardia, hypotension, drops Hgb.* |  |
| 2 | Subsequent Events | |
| Though initial troponin is negative, subsequent measure 6 hours later (which should have been ordered) is up to 7.2.   * *Patient continues to have chest pain* * *Patient develops SOB* * *Patient should be transferred to ICU* * *Kill the patient unless appropriately managed* |  |
