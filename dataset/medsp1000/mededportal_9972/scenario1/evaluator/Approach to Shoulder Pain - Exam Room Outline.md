| **Communication**   * Greet the patient * Introduce yourself * Start with an open-ended question * Attention to non-verbal skills   + eye contact, posture, spatial positioning   **History – eight questions:**   1. *“Note the patient’s* ***age****.”* 2. *“Was the* ***onset*** *sudden or gradual? (if sudden, any injury?”*) 3. *“****Where*** *is the pain?” “Can you point to it?”* 4. *"Any* ***past injuries****?"* 5. *“Do you play any* ***sports****?* 6. *"What type of* ***work*** *do you do?”* 7. *“Does the shoulder slip, pop, or feel* ***unstable****?”* 8. *“Do you have any other* ***medical*** *conditions?”*   **Initial exam – “Look, Move, Feel”** in four steps   * **Look** at *both* shoulders   + Skin   + Shape   + Position * **Move** the shoulder   1. **Active** (as the patient moves their shoulder, compare ROM and pain to the other shoulder)   2. **Passive** (is ROM and pain better when **you** move the shoulder) * **Feel** for tenderness (four structures)   + Acromioclavicular joint   + Sternoclavicular joint   + Biceps tendon   + Groove under the acromion process | | **Strength tests** (test the four muscles of the rotator cuff using three maneuvers) | | | |
| **1 - Supraspinatus**  Empty can test  Patient abducts arms to 90° with 30° of forward flexion and thumbs down  Examiner then tries to lower the arms  Pain without weakness 🡪 tendon inflammation  Pain with weakness 🡪 tendon tear | | | ![Empty Can test 9-13.tif](data:image/png;base64...) |
| **2 - Infraspinatus and teres minor**  Infraspinatus strength test  The infraspinatus externally rotates the arm  The patient flexes both elbows to 90°  Examiner resists external rotation  Pain and normal strength 🡪 tendon inflammation  Pain and weakness 🡪 tendon tear | | | ![Infraspinatus Test 9-16.tif](data:image/png;base64...) |
| **3 – Subscapularis**  Lift-off test  Subscapularis internally rotates the arm  Patient’s hand at mid-lumbar region  Slightly off of the back.  The examiner pushes hand towards the back while patient resists.  Note: don’t let patient “cheat” by flexing the wrist or using the tricep  Positive test = weakness | | | ![Hawkins test 9-12.tif](data:image/png;base64...) |
| **Provocative tests:** assess four other structures | | |  | **Assessment – four questions**   1. Was the **onset** of pain acute or gradual?    * If acute, was there an injury? 2. Is the structure causing the pain **intrinsic or extrinsic** to the shoulder?    * **Intrinsic:** the glenohumeral joint and closely surrounding structures.    * **Extrinsic:** the cervical spine, pleural membranes of the lung, gallbladder, or other structure causing pain that radiates to the shoulder. 3. If intrinsic to the shoulder, is it **glenohumeral or extra-glenohumeral**?    * **Extra-glenohumeral:** meaning the AC joint and the biceps tendon.      + + Speed’s test      + + Cross-arm test 4. If glenohumeral, then **which of the three components** is painful?  * **Rotator cuff** (one of the four muscles)   + + Empty can test   + + Infraspinatus strength test   + + Lift-off test * **Subacromion space** (containing the subacromion bursa and supraspinatus tendon)   + + Hawkins’s test * **Shoulder joint** (meaning the joint space with its articular surface and membranous capsule)   + pain on active ROM equals pain with passive ROM   + + Apprehension test | |
| **1 – Subacromion space**  Hawkins’s Test  Flex shoulder forward to 90 degrees  Internally rotate the arm  This pushes the supraspinatus tendon against coraco-acromial ligament  Positive = reproduction of pain | ![Hawkins test 9-10.tif](data:image/png;base64...) | |  |
| **2 - Biceps tendon**  Speed’s test  Hand in supination and elbow extended, patient flexes arm to about 60°  Examiner has one hand on the shoulder feeling the biceps tendon, other hand resists flexion of the elbow  Positive = reproduction of pain under the examiner’s thumb | ![Biceps Tendon 9-17.tif](data:image/png;base64...) | |  |
| **3 – AC joint**  Cross-arm Test  Flex shoulder to 90 degrees  Draw arm across the chest toward the other shoulder  Positive = reproduces pain | ![Hawkins test 9-11.tif](data:image/png;base64...) | |
| **4 - Glenohumeral instability**  Apprehension test  Patient seated with shoulder abducted 90° and elbow bent  Apply gentle anterior pressure on the posterior humerus while externally rotating the arm  Positive = patient feels apprehension  (Reproduction of pain is not a pos. test) | ![apprehension test 9-14.tif](data:image/png;base64...) | |
