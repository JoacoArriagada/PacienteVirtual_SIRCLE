# Title:

# A seizing infant in the post anesthesia care unit

# Resource files:

Word Document

# Resource utilization:

The document submitted provides a detailed outline for the utilization of the simulation scenario. The scenario would ideally be performed in the post anesthesia care unit (PACU) using a high fidelity baby simulator.

# Practical Implementation:

The scenario requires a high fidelity infant manekin and technician to operate the computer. Necessary adjuncts to the manekin include, airway management kit, intravenous access and fluid kit, code cart.

We have always run the scenario within the post anesthesia care unit where we have found a more realistic environment can be achieved.

The session faculty requires a facilitator, a distracter and a technician to run successfully.

We have always used at least 3 trainees/candidates – one as a team leader, an airway manager and an external cardiac massager. Further trainees can be utilized as necessary as medications administrators, documenters or observers.

Once the facilitators have set up the scenario the candidates are introduced to the environment and given the case briefing as described in the submission background. The candidates can either be introduced as a group to the scenario or if the development of a good working team is to be challenged further then just the initial team leader can be introduced to the scenario. The principle facilitator should introduce the PACU nurse distracter and the SIM baby technician to the team prior to the start of the scenario going “live”.

The set up takes approximately 15 minutes and due to the complexity of the scenario a pre scenario discussion should take place involving the faculty.

The simulation itself takes between 15 and 20 minutes.

The debrief afterwards is open ended, but usually takes at least 20 minutes.
