**Pediatric Code Cart Skills Session**

**Case #1**

Scenario: You are on the wards and it is 2AM when the code pager goes off. You arrive moments later to find the nurse standing by the patient’s bedside. The patient is an 8-year-old surgical patient whom you do not know. The nurse tells you that she found the patient unresponsive. At this same moment, another nurse brings the code cart to the room. Both of the nurses that are with you are new and are not familiar with the code cart.

Starting state: the patient is unresponsive and has no pulse.

End state: the patient has a pulse.

| **Necessary Critical Materials** | **Location (Institution-Specific)** |
| --- | --- |
| Back Board  Step Stool | Back of cart  Side of cart |
| Appropriately-sized BVM | Bottom Drawer ("First Five Minutes Drawer") |
| Defibrillator  Pads  Consider monitor leads  Consider pulse ox | Top of cart  Bottom Drawer ("First Five Minutes Drawer") |
| Broselow Tape | Bottom Drawer ("First Five Minutes Drawer") |
| IV  Tape  Tegaderm  Extension tubing  IO  Flush | Access Drawer  Brought by PICU team |
| Code Dose Epinephrine | Medication Tray |
