**Pediatric Code Cart Skills Session**

**Case #1**

Scenario: You are on the wards and it is 2AM when the code pager goes off. You arrive moments later to find the nurse standing by the patient’s bedside. The patient is an 8-year-old surgical patient whom you do not know. The nurse tells you that she found the patient unresponsive. At this same moment, another nurse brings the code cart to the room. Both of the nurses that are with you are new and are not familiar with the code cart.
