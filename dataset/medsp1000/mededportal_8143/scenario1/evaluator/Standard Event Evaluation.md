# Facilitator Notes for Acute Respiratory Failure in Infant

Evaluation tool was designed to evaluate a paramedic with an unskilled team member. Form could also be used to evaluate event as a whole with multiple participants, noting which role each participant played Abnormalities for this scenario are under breathing including: Wheezing initially Apnea Absent breath sounds in left lung for pneumothorax If scenario takes place on an ambulance, supplemental testing questions are not applicable and handoff would refer to notifying medical command
