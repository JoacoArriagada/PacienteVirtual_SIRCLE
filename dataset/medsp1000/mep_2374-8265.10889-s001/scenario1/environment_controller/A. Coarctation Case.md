| **Appendix A: MedEdPORTAL Simulation Case Template**  **SIMULATION CASE TITLE:** “Critical Coarctation of the Aorta: A Pediatric Simulation Case for Pediatric ICU Fellows, Critical Care Nurses, and Pediatric Residents”  AUTHORS: Charles Bergman, M.D., Joy Howell, M.D. | |
| **PATIENT NAME:** Isabella  **PATIENT AGE:** 3 weeks old  **CHIEF COMPLAINT:** shortness of breath and poor feeding | |
|  | |
| **Brief narrative description of case** | Isabella is a 3-week-old, ex full-term infant who presented to the ED with a 2-day history of respiratory distress and one-day history of poor feeding. In triage, the patient was noted to be febrile, tachycardic, tachypneic, and with transient pulse oximetry reading of 95% on room air per report. The ER assessment was that of bronchiolitis; a partial sepsis workup was also initiated. Patient is now admitted to the PICU as she seemed more distressed after urinary catheterization. |

| **HPI** | Isabella is a 3-week-old ex-full-term girl who presented to the ED with 2-day history of respiratory distress and one day history of poor feeding. In triage, she was febrile (Temp 100.4 rectally), tachypneic (RR 70s) and tachycardic (HR 185). Pulse oximetry was not picking up well, but there was a transient read of 95% per report while on room air. The ER assessment was that of bronchiolitis. After 3 albuterol nebulizer treatments, the HR increased to 220’s. A partial sepsis workup was initiated; however, patient lost their IV during urinary catheterization and received IM antibiotics after multiple failed attempts to re-establish IV access. Patient was admitted to the PICU as she seemed more distressed after catheterization. The ER thinks child should be placed on CPAP for bronchiolitis and impending respiratory failure and has asked that a PICU bed be expedited. | | |

| Instructor Notes - Changes and CASE Branch Points | | |
| **Intervention / Time point** | **Change in Case** | **Additional Information** |
| Beginning of Case | When asked, Mother (standardized patient) will explain that patient has had increased respiratory distress and poor feeding for the past day |  |
| 2-min: Patient placed on monitor (if not on monitor already); nurse completes initial assessment | Monitor will show patient with HR 220, RR 77 | If pulse oximeter is placed on upper extremity it will intermittently read 95% without good waveform (this may have to be communicated verbally by instructor)  If pulse oximeter is placed on lower extremity it will read 85% without good waveform (this may have to be communicated verbally by instructor) |
| Participants hook up blood pressure cuff ask for blood pressure | If blood pressure cuff is placed on upper extremity it will read 90/60  If blood pressure cuff is placed on lower extremity it will be **unobtainable** |  |
| Peripheral IV is placed | Facilitator will communicate to the team whether the peripheral IV is working (facilitators can state peripheral IV is not working if obtaining IV access is a desired nursing skill to practice) | If the peripheral IV is blown, intraosseous access must be obtained |
| Labs are obtained (e.g., ABG, BMP,CBC ) | After a brief delay the facilitator will communicate the results of the labs:  The ABG results should be available first (within 2-3 min of being drawn) followed by CBC and BMP (~ 7 min).  *- ABG (if drawn from UE):*  *6.99/15/100/-22 / 99%/ Lactate 5/ Ica 1. 05/K 5.5/Glc 50/ Hgb 15*  *- ABG (if drawn from LE):*  *7.1/ 26/ 58/ -18/ 89%/ Lactate 7/ Ica 1.01/ K 6/ Glc 50/ Hgb 15*  - CBC shows WBC 18 with left shift  - BMP shows *Na 130, K 5.5, Cl100, bicarb 7, bun 32, creatinine 1.1, glucose 44, Ca 8.0* | If repeat lab work is done, the acidosis will not improve above 7.15 unless prostaglandin E1 is started |
| Fluid resuscitation is initiated (e.g., 10-20cc/kg NS bolus) | The HR will improve but only slightly; patient will remain tachycardic | HR will continue to improve minimally (to 200) and patient will remain tachycardic with each subsequent bolus |
| Chest x-ray is obtained | After a brief delay the facilitator will provide the chest x-ray (*clear lungs, mild cardiomegaly, no increased vascular markings)* |  |
| Initiate inotropic support (with epinephrine/ dobutamine/dopamine) | Minimal immediate improvement in patient’s clinical status |  |
| Administer glucose for hypoglycemia | Minimal immediate improvement in patient’s clinical status | Repeat blood glucose is improved (90) but child remains in shock |
| Administer bicarbonate for acidosis | Minimal immediate improvement in patient’s clinical status |  |
| Broaden antibiotic coverage for presumed sepsis | No obvious change/ improvement in patient’s clinical status |  |
| Initiate prostaglandin E1 (max 0.1mcg/kg/min) | Patient’s perfusion, tachycardia and tachypnea will improve; (e.g., capillary refill and femoral pulses) will improve | HR – 175  RR - 40 |
| Cardiology/Cardiothoracic Surgery is paged/called | Facilitator will communicate to the team that Cardiology/Cardiothoracic Surgery is on their way |  |
| Shortly after initiation of prostaglandin E1 | Respiratory rate will improve; after some time, respiratory rate will continue to decrease until baby becomes apneic. O2 saturations will begin to fall again at this time point. | RR - 0 |
| Baby is intubated | The simulation is complete | Repeat blood gas demonstrates some improvement in severity of lactic / metabolic acidosis |
