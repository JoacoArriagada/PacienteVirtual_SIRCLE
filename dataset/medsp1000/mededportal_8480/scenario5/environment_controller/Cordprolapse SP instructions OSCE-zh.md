不良事件后告知 – 医源性脐带脱垂

你是 Sherry Reynolds，30岁女性，足月活跃期入院待产。你在宫口开大 $6 \mathrm { { c m } }$ 后接受了硬膜外麻醉，随后一年级住院医师请产科医生在她为你人工破膜时进行监督。破膜时脐带先脱出，因此必须实施急诊剖宫产。手术顺利，但宝宝经过长时间复苏后入住新生儿重症监护室——宝宝娩出时看起来几乎没有生命体征。

你将穿医院病号服，并接一条假的静脉输液管。   
还会有一条假的导尿管接到尿袋。

本次会谈的目标是让医生解释发生了什么，最好表达歉意，并回应你对刚经历并发症的担忧。

表现方式：比起愤怒或指责，更偏向失望和难过。

你知道什么？

情况如上——这是你的第一胎，分娩原本进展顺利，但硬膜外后宫缩变慢，所以护士和住院医师认为人工破膜可以加快产程。低年资住院医师在上级医师（即正与你会谈的医生）监督下实施了人工破膜，随后发生了情况——脐带脱出——他们立刻把你送进手术室做急诊剖宫产。

你应该说什么？

“为什么会发生这种事？”   
“我非常失望，本来一切都很顺利。”   
“我真的不想做剖宫产。”   
“我的宝宝会没事吗？”
