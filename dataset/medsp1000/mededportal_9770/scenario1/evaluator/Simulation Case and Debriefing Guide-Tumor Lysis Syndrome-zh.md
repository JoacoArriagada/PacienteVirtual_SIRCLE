1. **标题（TITLE）：肿瘤溶解综合征（Tumor Lysis Syndrome）**
2. **目标受众（TARGET AUDIENCE）：** 医学生、住院医师
3. **学习目标（LEARNING OBJECTIVES）**

**A) 主要目标（Primary）**

1. 在本次模拟结束时，学习者将能够通过获取恰当且准确的病史来识别肿瘤溶解综合征（Tumor Lysis Syndrome）。

2. 在本次模拟结束时，学习者将能够通过进行恰当且准确的体格检查来识别肿瘤溶解综合征（Tumor Lysis Syndrome）。

3. 在本次模拟结束时，学习者将能够识别并处理与肿瘤溶解综合征相关的高钾血症（hyperkalemia）。
4. 在本次模拟结束时，学习者将能够处理与肿瘤溶解综合征相关的低钙血症（hypocalcemia）。
5. 在本次模拟结束时，学习者将能够处理与肿瘤溶解综合征相关的高尿酸血症（hyperuricemia）。

**B) 关键操作核对清单（Critical Actions Checklist）**

临床状态 #1：就诊表现（Presentation）

1. 采集恰当病史
2. 将患者连接监护仪
3. 开具恰当的实验室检查
4. 在心电图（EKG）上识别高钾血症
5. 使用胰岛素、葡萄糖、沙丁胺醇（albuterol）、碳酸氢盐、Kayexelate 治疗高钾血症
6. 使用静脉补液（IVF）、袢利尿剂（loop diuretic）、Rasburicase 治疗高尿酸血症
7. 会诊肿瘤科与肾内科

临床状态 #2：高钾血症、低钙血症与脱水加重

1. 识别生命体征恶化

2. 在监护仪或心电图上识别 QRS 波群增宽

3. 给予积极静脉补液（IVF）

4. 在高钾血症背景下针对 QRS 增宽给予钙剂。

临床状态 #3：患者稳定，收入 ICU

1. 向 ICU 医师进行患者交接报告
2. 高钾血症治疗后复查心电图（EKG）
3. **环境（ENVIRONMENT）**
   1. **实验室布置（Lab Set Up）：** 模拟室应具备与城市急诊复苏室相同的能力。可设置带单向镜的控制室，供模拟病例导演观察病例进展。他们也可通过无线电与模拟室内护士沟通。或者，也可采用更简化的布置，即指导教师与模拟人和学习者在同一房间。模拟参与者可通过模拟室内连接至控制室的电话呼叫会诊医生与收治团队。
   2. **模拟人布置（Manikin Set Up）：** 模拟急诊科配备可创建多种生理状态的模拟人，这些状态可被编程为随时间恶化并对治疗操作做出反应，或由指导教师直接操控。模拟人应穿着普通便装。模拟人初始显示的生命体征应为 HR 120 BP 100/60 RR 20 Temp（若被询问）98.7 Pulse Ox 98% RA。
   3. **道具（Props）：**
      1. 复苏推车，配备用于气管插管、中心静脉置管、动脉置管、复苏药物、静脉输液设备、个人防护装备的器材。
      2. “心电图机（ECG machine）”与心电图，或仅心电图：
         1. 窦性心动过速伴高尖 T 波。
         2. 窦性心动过速伴 QRS 增宽
      3. “便携式 X 线机（Portable X-ray Machine）”和/或正常胸片（CXR）
      4. **药**物（Medications）：胰岛素、葡萄糖、碳酸氢盐、沙丁胺醇、葡萄糖酸钙、Kayexelate、Rasburicase、抗生素、生理盐水，
4. **角色（ACTORS）**
   1. 角色
      1. 护士（RN）：可由任何熟悉模拟人与复苏室布置的医务人员扮演。护士应佩戴耳机/无线电以便与镜后病例指导教师沟通。若无额外人员，带教者可通过麦克风口头扮演护士角色。
      2. 心电图与 X 线技师、呼吸治疗师和药师：任何额外人员均可担任技师、治疗师或药师。
      3. 患者（在控制室）：患者由模拟人扮演。控制室内模拟导演可通过麦克风以患者身份说话。
      4. 会诊医生（在控制室，通过内部电话发声）：可由运行病例的任一指导教师扮演。
      5. 参与者（住院医师、专科进修医师或高年级学生）：
      6. 次要参与者：可由医学生或其他住院医师/进修医师担任，协助病例处理。他们可呼叫会诊医生或收治团队，也可协助操作流程。
      7. 本病例可在更少人员配置下运行，同一人可承担多个角色。

**指南（Guide）**：若学习者未问出淋巴瘤病史及近期开始化疗，护士可询问患者：“你还有其他病史吗？”。此时，患者可告知学习者其近期被诊断为淋巴瘤，且 3 天前开始化疗。

1. Y [ ]  N [ ]  将患者置于监护并获取完整生命体征

**指南（Guide）**：若学习者未要求护士测完整生命体征并将患者连接监护，护士可询问学习者是否需要生命体征和/或监护

1. Y [ ]  N [ ]  开具了恰当化验

Y [ ]  N [ ]  CBC

Y [ ]  N [ ]  生化全套（Chemistry panel）

Y [ ]  N [ ]  尿酸（Uric acid）

Y [ ]  N [ ]  乳酸（Lactic acid）

**指南（Guide）**：若学习者未开具任何化验，护士应询问其是否要开检查？

1. Y [ ]  N [ ]  开具心电图（EKG）

**指南（Guide）**：若学习者未开具心电图（EKG），护士可说：“那个监护看起来有点异常。你还需要其他检查吗？”

1. Y [ ]  N [ ]  在心电图（EKG）上识别高钾血症

**指南（Guide）**：初始心电图（EKG）提示高尖 T 波。若学习者未识别高尖 T 波，护士可提示其看心电图并说：“这张心电图看起来不太正常。”

1. Y [ ]  N [ ]  识别并治疗高钾血症

Y [ ]  N [ ]  胰岛素 + 葡萄糖（Insulin & glucose）

Y [ ]  N [ ]  沙丁胺醇（Albuterol）

Y [ ]  N [ ]  碳酸氢盐（Bicarbonate）

Y [ ]  N [ ]  Kayexelate

**指南（Guide）**：若患者高钾血症未被积极治疗，患者应快速失代偿。学习者应在血钾结果返回前即治疗高钾血症。除非患者开始失代偿（QRS 增宽、精神状态改变、低血压），否则护士不应提示高钾治疗。若此时学习者仍未治疗高钾，护士可被提示将血钾水平作为危急值告知学习者。若学习者在结果显示高钾后仍不治疗，患者应进展为监护上正弦波并发生心脏停搏。此时护士可询问学习者是否要处理该异常血钾结果。

1. Y [ ]  N [ ]  识别并治疗高尿酸血症

Y [ ]  N [ ]  静脉补液（IV fluids）至少 2 升

Y [ ]  N [ ]  袢利尿剂（Loop diuretic）

Y [ ]  N [ ]  Rasburicase

**指南（Guide）**：护士可向学习者提供尿酸升高结果。若学习者未使用静脉补液、袢利尿剂和 Rasburicase 治疗，护士应询问是否还有其他应给予的治疗。若学习者不确定应给何种治疗，护士可询问其是否需要会诊肿瘤科？

1. Y [ ]  N [ ]  会诊肿瘤科（Oncology）

**指南（Guide）**：若学习者在患者病程早期即会诊肿瘤科，肿瘤科医生应设定为不可联系。只有在考虑肿瘤溶解综合征诊断并且患者已接受静脉补液（IVF）与高钾治疗复苏后，肿瘤科医生才可联系。若学习者在诊断上明显受阻，带教者可更早让肿瘤科医生可用。

1. Y [ ]  N [ ]  会诊肾内科（Renal）

临床状态 2 – 脱水与高钾血症恶化（WORSENING DEHYDRATION and HYPERKALEMIA）

1. Y [ ]  N [ ]  识别生命体征恶化

**指南（Guide）**：若高钾血症未治疗且患者未积极容量复苏，患者将开始恶化。心动过速与低血压应加重。

1. Y [ ]  N [ ]  积极静脉液体复苏，至少 2L IVF

**指南（Guide）**：若未下达 2 升静脉补液，心动过速与低血压会加重。此时护士可说：“患者仍然低血压，还需要更多静脉补液吗？”

1. Y [ ]  N [ ]  在监护或心电图（EKG）上识别 QRS 增宽

**指南（Guide）**：当患者失代偿时，监护应调整为 QRS 增宽。若学习者未识别，护士可再次说：“监护上的 QRS 看起来和之前不一样。我们要做点什么吗？”

1. Y [ ]  N [ ]  用钙剂治疗 QRS 增宽

**指南（Guide）**：若 QRS 增宽未立即用钙剂治疗，患者应进展为监护正弦波并发生心脏停搏。

1. Y [ ]  N [ ]  在钙剂治疗后重新评估 QRS

**指南（Guide）**：学习者应在患者接受钙剂后查看心电图（EKG）或监护。若未查看，护士可问：“你觉得监护看起来好一些了吗？”

临床状态 3 – 患者稳定并收入院（STABILIZATION and ADMISSION of PATIENT）

1. Y [ ]  N [ ]  将患者收入 ICU

**指南（Guide）**：最终该患者需要明确去向。患者治疗后，学习者应联系 ICU 医生收治。若未联系，护士可说：“我们需要腾出这个房间。这个患者你打算怎么安排？” 当学习者向 ICU 医生电话交接时，是让他们回顾其认为的患者诊断以及已实施治疗的好时机。

1. Y [ ]  N [ ]  高钾治疗后复查心电图（EKG）

**指南（Guide）**：高钾治疗后应重复心电图（EKG）。若学习者未下达复查心电图，护士可询问其是否需要。
